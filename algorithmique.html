Introduction

L'algorithmique permet de résoudre un problème en suivant une suite d'instructions organisées. Dans cette page, je présente trois algorithmes : la recherche du maximum, le tri à bulles et la recherche séquentielle.

1. Recherche du maximum

Idée générale

Cet algorithme permet de trouver le plus grand nombre dans un tableau.

Pseudo-code

    Début
        T = [12, 5, 18, 9]
        max = T[0]  
        Pour chaque élément x de T
            Si x > max alors
                max = x
            Fin Si
        Fin Pour  
        Afficher max
    Fin

Exemple pas à pas

Tableau : [12, 5, 18, 9]

  • On commence avec max = 12.
  • 5 est inférieur à 12, donc max reste 12.
  • 18 est supérieur à 12, donc max devient 18.
  • 9 est inférieur à 18, donc max reste 18.

Résultat : 18

Traduction en Python


    T = [12, 5, 18, 9]
    maximum = T[0]   
    for x in T:
        if x > maximum:
            maximum = x   
    print("Le maximum est :", maximum)

2. Tri à bulles (Bubble Sort)

Idée générale

Le tri à bulles permet de classer les nombres dans l'ordre croissant en comparant deux éléments voisins et en les échangeant si nécessaire.

Pseudo-code

    Début
        T = [5, 2, 8, 1]
    
        Pour i de 0 à n-2
            Pour j de 0 à n-i-2
                Si T[j] > T[j+1] alors
                    Échanger T[j] et T[j+1]
                Fin Si
            Fin Pour
        Fin Pour
    
        Afficher T
    Fin

Exemple pas à pas

Tableau initial : [5, 2, 8, 1]

  • Premier passage : [2, 5, 1, 8]
  • Deuxième passage : [2, 1, 5, 8]
  • Troisième passage : [1, 2, 5, 8]

Résultat : [1, 2, 5, 8]

Traduction en Python


    T = [5, 2, 8, 1]
    n = len(T)   
    for i in range(n - 1):
        for j in range(n - i - 1):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]
    print("Tableau trié :", T)

3. Recherche séquentielle

Idée générale

La recherche séquentielle consiste à parcourir un tableau élément par élément pour trouver une valeur recherchée.

Pseudo-code

    Début
        T = [3, 8, 5, 1]
        valeur = 8
        position = -1
        Pour i de 0 à n-1
            Si T[i] = valeur alors
                position = i
                Arrêter la boucle
            Fin Si
        Fin Pour  
        Si position != -1 alors
            Afficher "Valeur trouvée"
        Sinon
            Afficher "Valeur non trouvée"
        Fin Si
    Fin

Exemple pas à pas

Tableau : [3, 8, 5, 1]

Valeur recherchée : 8

  • Position 0 : 3 est différent de 8.
  • Position 1 : 8 est égal à 8.
  • La valeur est trouvée à la position 1.

Traduction en Python


    T = [3, 8, 5, 1]
    valeur = 8
    position = -1   
    for i in range(len(T)):
        if T[i] == valeur:
            position = i
            break   
    if position != -1:
        print("Valeur trouvée à la position", position)
    else:
        print("Valeur non trouvée")
